# AMASS 下载与交接

本项目目前仅做非商业研究。AMASS 是否可以用于你的具体研究及后续公开，请以官网当前协议和组成数据集的条款为准；你需要本人决定是否注册并接受协议，我不能替你接受。

1. 打开 [AMASS 注册页面](https://amass.is.tue.mpg.de/register.php)，按页面要求填写资料、阅读隐私声明与使用条款并完成账号注册和邮箱验证（实际字段和流程以官网为准）。
2. 登录 [AMASS 官网](https://amass.is.tue.mpg.de/)，在下载页面查看可选的数据版本与子数据集，选择一份用于非商业研究的小型子集下载；不必一次下载全量。下载页面可能会要求另行确认相应许可。
3. 将下载的原始压缩包，或保留原目录结构的解压文件，放到本项目 `data/amass/` 文件夹下。可以手动在文件资源管理器中创建该文件夹；不要修改文件名。这里是你的本机共享工作区，不必上传聊天。
4. 完成后告诉我文件夹路径和下载项名称即可；不要发账号密码或 API 密钥。AMASS 许可是个人单用户许可，并限制向第三方提供数据。使用 Codex 等服务处理可能涉及第三方访问或传输；应先核对服务的数据处理方式及许可，必要时取得授权。确认许可允许后才能实际读取和实验。
5. SMPL+H 人体模型需另行在 [MANO 官方站点](https://mano.is.tue.mpg.de/)阅读并同意对应许可后下载；本次已下载适合 AMASS 的 Extended SMPL+H 16 betas 版本，放入 `data/body_models/`。AMASS 本身不是 IMU 实测数据。

本地骨架实验的细节和局限见《研究原型评审交付说明》。默认离线、没有向外部模型发送 AMASS 数据。

`data/amass/` 和 `data/body_models/` 已在项目 `.gitignore` 中列出，减少意外提交到 Git 的风险，但这不等于任何形式的访问控制。不要擅自重新分发数据或将受限数据及衍生内容上传第三方服务；具体以适用许可为准。
