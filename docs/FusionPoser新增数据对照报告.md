# FusionPoser 新增数据对照报告

> 历史实验记录：保留当时的方案、数据范围和结果。后续进展见 [补充实验报告](三项优化_跨人和视觉补充实验_20261108.md)，当前待办见 [后续工作](ROADMAP.md)。

日期：2026-11-08。研究实验，结果不用于训练指导、医疗判断或实际设备精度承诺。

## 给非专业读者的结论

在同样两段新录制上比较，往训练数据中加入两段录制后，平均关节点距离误差都下降了：

| 测试录制 | 加入前 | 加入后 | 加入后固定平均姿态基线 |
| --- | ---: | ---: | ---: |
| 0625174933 | 13.279 | 7.774 | 16.493 |
| 0625175157 | 20.578 | 14.389 | 21.324 |

数值暂按厘米理解；公开数组的单位和关节点字段排列尚待进一步核实。每个数是对应录制所有帧中、20 个三维点的平均欧氏距离。越低越好。基线是不看当前传感器、始终输出训练集平均姿态的简单方法。

这次确实是对**同一测试录制**进行加入数据前后的比较。但只有两段测试录制，不能据此断言一般情况下都会改善；它们的受试者身份不明，不能称为跨人测试。早先 11.114 的结果来自另一段录制，不能与本次数字直接比较为下降幅度。

需要注意，第二段的平均误差虽降低，但逐帧平均误差的第 95 百分位从 33.595 上升到 41.563；这说明部分误差较大的画面可能更差，并不是每一帧都改善。第 95 百分位不是单个关节的最大误差，也不衡量动作安全。

## 固定方案及来源

在查看两段测试的结果之前固定以下方案，不以测试分数调参：

- 原训练组：`0625180826`、`0625181142`、`0625181240`，共 2,915 行。
- 新增训练组：`0625175446`、`0625175813`，加入后训练组共 23,951 行。帧有时间连续性，行数不是独立人数或独立动作数。
- 留出测试组：`0625174933`（3,489 行）、`0625175157`（3,048 行）。这两段结果现在已被查看，后续不再是全新未接触的测试集。
- 两个模型均使用窗口第 7 个时间点的 43 维输入、前 60 个输出数值，岭回归参数固定为 200。新数据并未参与原有 200 参数的选择；本轮没有用测试集调参。训练帧数变化也会改变该固定正则项的相对作用，因此结果不能单独归因于数据数量。
- 数据来自 [FusionPoser 上游固定版本](https://github.com/LuzyCat/FusionPoser/tree/e8ba6f89b2f6cc031b37c55dd72fc674192df86f/Dataset/real)。新增文件与该版本的 Git blob 摘要核对一致；历史三组按既有 SHA-256 核验。以 `.npz` 命名，实际为 NPY 数组；读取禁用 pickle。

本轮原始数据存储于本机，不提交数据文件。数组布局、关节名称及单位仍属于依据论文和样本结构作出的解释，未经作者逐字段确认；当前 20 点指标也不能直接等同论文的 15 关节指标。此项目模型是简单岭回归基线，不是 FusionPoser 论文模型。

## 核验与复现

- 两组 X、Y 维度、行数和有限数值检查通过；所有新数据文件的上游摘要核验通过。
- 将原三段完整训练出的 NumPy 模型与既有纯 Python 模型比较，两段测试各抽取 100 帧，预测最大差异分别约 `4.83e-12`、`1.56e-11`；误差统计结果差异约 `1e-13`。
- 检查测试帧与训练帧的 43 维特征和 60 维标签完全相同的行，均为 0；此检查不能排除相邻录制或相同受试者等关联。
- 环境：Windows，Python 3.11，NumPy 2.4.6。源数据应位于 `data/fusionposer/`，原三组和四组新增数据共 14 个文件；执行 `py -3.11 examples/fusionposer_expanded.py`。脚本不会下载、修改或输出原始数据；如数据分放目录，可通过 `--old-dir` 和 `--new-dir` 指定。

本实验未将模型接入 App，也没有测量真实用户、真实设备或训练指导效果。下一步应确认上游数据字典与受试者划分，再准备更多身份明确的独立测试录制；不能根据已查看的两段反复调参后继续把它们称为独立测试。
