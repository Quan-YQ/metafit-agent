# FusionPoser 骨架预测误差：阶段性诊断

> 历史实验记录：保留当时的方案、数据范围和结果。后续进展见 [补充实验报告](三项优化_跨人和视觉补充实验_20261108.md)，当前待办见 [后续工作](ROADMAP.md)。

日期：2026-11-08。目的：核对现有误差计算、找出可能原因，并做小规模离线对照。这里的预测器是本项目的岭回归基线，并非 FusionPoser 作者的神经网络；所有结果仅用于研究，不用于训练指导。

## 一、数据与计算核对

- 作者论文使用 6 个 IMU 加头部高度；输入由 10 个时间点、每点 43 个数构成。当前基线只取其中第 7 个时间点的 43 个数，不使用完整时间序列。论文的骨架关节位置使用厘米，但公开数组每列的具体语义及预处理仍需作者确认。[论文](https://www.mdpi.com/1424-8220/22/13/4846)、[作者数据仓库](https://github.com/LuzyCat/FusionPoser)。
- 作者论文评估 15 个主要关节；当前基线把前 60 个输出按 **20 个三维点**计算平均欧氏距离。因此，当前数字不等同于论文报告的 MPJPE，不能直接比较。
- 三段现有录制中，从第 63 个数（索引 62）开始按四元数组合，其长度在 1% 范围内的比例均为 100%；沿当前假设的骨架树，各段骨长变化接近零。这些现象**支持**当前数据排列假设，但不能证明每个关节名称、坐标方向和来源完全正确。
- 用已知 3-4-5 三维距离验证误差公式，并用独立 NumPy 线性代数计算对比原岭回归前 30 个预测，最大绝对差约 `1.8e-12`。这说明实现与该公式一致；不证明输入列解释或标签真实无误。

## 二、为什么先前误差可能很大

原训练录制 `0625180826` 的头部高度范围约 **141.8～156.9**。在另外两段测试录制中，分别约 **91.1% 和 100%** 的帧超出这个范围；按论文的描述高度使用厘米。

这说明原模型要处理大量训练时未覆盖的输入，且它只用一段录制训练。数据分布差异是误差较大的一个合理解释，**不能仅凭这一现象断言是唯一原因**；字段顺序、设备标定、同步及模型能力仍需核对。

## 三、小规模验证：选择参数，比较简单基线

先在原有三段录制里轮流留出一段作为测试，剩余两段分别用于训练和挑选岭回归参数，选好后再用这两段重新训练。每次测试录制均未参与**该轮**训练和参数选择。结果如下（单位按论文描述暂记 cm）：

| 测试录制 | 参数选择后的误差 | 训练集均值姿态基线 | 原固定参数实验误差 |
|---|---:|---:|---:|
| `0625180826` | 10.872 | 29.028 | 10.872 |
| `0625181142` | 15.740 | 25.126 | 30.347 |
| `0625181240` | 11.652 | 21.028 | 8.060 |

三次都优于简单基线，但第三段比原固定参数更差。这些录制在之前已经被查看过，且身份未知，**不能视为全新测试或跨人验证**。

运行前固定方案见 [留出实验方案](FusionPoser留出实验方案.md)：在三段开发录制中选参数，再用它们重新训练，最后检查未参与选择的 `0625174249`。在本次执行中：

- 两个样本文件的 SHA-256：X 为 `00c62d402f6959f6b8eab22421b2805910aac4eab0d1b0163e364e7092461936`，Y 为 `1459926ae343f1d8df6e4c258f4d15bad4704d9c78378de1e2caa1c091ba1af2`。

这个结果只说明：按照当前字段解释和一次固定测试，预测优于该简单基线。**它不代表平均每次实际使用都只有 11.1 cm 误差**，也不证明可以跨人、实时使用或用于训练指导。该额外录制现已被查看；后续要评价泛化能力，需要另找未用于开发的新数据和明确的参与者划分。

## 五、复现

在项目目录中先下载前三段公开数据，再运行诊断和额外留出实验：

```powershell
py -3.12 examples/fusionposer_fetch.py --download
py -3.12 examples/fusionposer_diagnostics.py
py -3.12 examples/fusionposer_holdout.py --download-heldout
```

留出下载固定文件和 Git 摘要、校验后才保存，不覆盖已有数据、不自动重试。之后去掉 `--download-heldout` 可离线重现。公开数据文件被 `.gitignore` 排除，不随仓库提交；这些脚本无需模型 API 或密钥。

本次隔离副本全量回归为 **690 passed、4 skipped**；跳过的 4 项是 NumPy 相关测试，已在 Python 3.11 / NumPy 环境单独通过。随后新增一项留出数据读取顺序检查，新旧诊断相关测试共 **8 项通过**；全量结果不包含这最后一项新增测试。
