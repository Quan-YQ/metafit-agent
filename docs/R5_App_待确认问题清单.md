# MetaFit × App：待确认问题清单

> `0.3.0-draft`｜**proposed / 未经团队确认**。负责人、截止时间和结论均待双方填写。`0.3.0` 安全修订已在本地模拟范围有条件通过复核，这不代表本清单、App 联调或真实场景已经通过。

| 优先级 | 问题与建议 | 建议参与方 | 决定人 / 截止 | 未决的影响 |
|---|---|---|---|---|
| 联调前 | **安全提示与本地兜底**：网络失败、过载、无法解析 body 和未归属报告时，App 怎样提示、如何重新报告？建议 App 保留独立的本地处理路径。 | App、Agent、产品、专业人员 | 待定 | 不能只靠服务端 400/503 或默认错误页保证提示可见 |
| 联调前 | **安全文案、医疗边界、紧急升级**：由谁审查触发条件、文案、何时求助及升级渠道？ | **产品、专业人员、App、Agent 联合审查** | 待定 | 当前固定提示不是医疗建议或经专业验证方案 |
| 联调前 | **身份和权限**：真实账号、设备绑定、会话归属及访问控制由谁提供和校验？ | App、后端、安全、Agent | 待定 | 模拟 ID 不证明身份；不能接入真实数据 |
| 联调前 | **事件和指标**：哪些动作、字段、单位、质量、来源、事件 ID 与动作理解结果可用？缺失如何表达？ | App、动作理解负责人、Agent | 待定 | 当前只支持模拟；Human+ 实际能力未核实 |
| 联调前 | **确认与显示**：何时允许用户主动发起、展示、跳过，关闭后如何进入新会话？ | App、产品、Agent | 待定 | 自动弹问、静音和免打扰可能被混用 |
| 联调前 | **反馈投递**：候选内容由谁复核、何时过期、在哪里展示或播报？ | App、Agent、产品、专业人员 | 待定 | `may_display=false`，当前不提供投递许可 |
| 联调前 | **错误与重试**：201/200 恢复含义、`record_state=decided`、超时 400、范围冲突 code 与重试策略怎样定义？ | App、Agent | 待定 | 不同客户端可能产生不同解释或重复调用 |
| 联调前 | **版本和验证**：是否接受从 0.3.0 起的兼容约定、如何通知升级、谁运行完整 OpenAPI 验证？ | App、Agent | 待定 | `0.2.1→0.2.2` 是历史例外；`0.2.2→0.3.0` 改变畸形不适请求错误码 |
| 真实数据前 | **数据保留与删除**：存储位置、加密、最小化、保留期、删除、备份和同步副本如何处理？ | App、后端、合规、安全 | 待定 | 本地模拟库明文、逻辑删除不等于物理擦除 |
| 真实数据前 | **多实例及设备**：不同进程、设备和请求之间如何同步不适状态及最终投递复核？ | App、后端、Agent、安全 | 待定 | 现有保证仅在单协调器实例内 |
| 联调前 | **联调环境**：如何从 App 可访问 Agent？本机 loopback 是否足够？测试设备、数据、权限和负责人是谁？ | App、Agent、项目负责人 | 待定 | `127.0.0.1` 不能直接连接另一台手机或电脑 |

本清单提出的是讨论顺序，不分配实际责任，不代表任何外部人员或团队已承诺。
