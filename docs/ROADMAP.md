# 后续改进

更新时间：2026-11-10。

## 数据与动作捕捉

- 接入 HumanPlus 人一智能实验室专有的宽松衣物动作捕捉系统，先在固定协议下核对时间同步、坐标系、身体点定义和录制质量。
- 用实验室真实动捕数据复核预测骨架与读图流程；公开 FusionPoser/CIP/CMU 数据只作为工程验证，不作为实验室精度结论。
- 保留少量公开样本用于离线测试和链路回归，不把公开数据的结果外推为真实设备或真实训练者的精度。

## 视觉识别

- 扩大独立录制、人物和动作类别；当前扩展集为 5 段公开录制、90 张图，同源窗口的 forward/reverse/static 版本不是独立人物。
- 针对上升/下降与阈值边缘样本增加人工几何复核，分别记录读图错误、格式错误和主动不确定。
- 视觉观察只作为模拟事实进入 Agent 检查，不直接生成或展示训练建议。

## Agent 与接口

- 扩大模拟事实缺失、冲突、异常返回、免打扰和不适优先的组合场景。
- 由 App、产品和相关专业负责人确认 [对接问题](R5_App_待确认问题清单.md)。
- 确定真实身份、设备绑定、数据保护、消息时效及投递流程后开展端到端联调。

这些是后续事项，不属于当前版本已完成的范围；当前验证见 [改进记录](../CHANGELOG.md)。
