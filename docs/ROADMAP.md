# 后续改进

更新时间：2026-11-08。已完成的实验见 [补充报告](三项优化_跨人和视觉补充实验_20261108.md)；本页列出仍需验证的工作。

## 骨架预测

- 确认 FusionPoser 的逐列布局、时间窗口及单位；其跨录制成绩与 CIP 的节段指标分别报告。
- 在更多独立 CIP 受试者上评估。新增测试对象应先固定划分，再读取结果。
- 验证无需参考姿态辅助的传感器同步、坐标标定与独立头高输入。
- 单独分析手脚等末端误差和动作类别差异；改善平均值时同时检查较差帧。

## 视觉识别

- 针对升高/降低混淆，建立人物与动作更均衡的新测试集，分别记录错误和不确定。
- 区分一般视觉模型、参考线辅助读图和固定颜色标记工具的结果。
- 引入独立人工复核，逐步扩展到动作过程，而不是只检查首尾髋部高度。

## Agent 与接口

- 扩大模拟事实缺失、冲突、异常返回、免打扰和不适优先的组合场景。
- 由 App、产品和相关专业负责人确认 [对接问题](R5_App_待确认问题清单.md)。
- 确定真实身份、设备绑定、数据保护、消息时效及投递流程后开展端到端联调。

这些是后续事项，不属于本次仓库整理的完成条件；本次变更及验证见 [改进记录](../CHANGELOG.md)。
