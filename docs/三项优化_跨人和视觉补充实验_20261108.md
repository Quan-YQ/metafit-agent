# MetaFit 三项优化：补充实验结果（2026-11-08）

## 1. 骨架预测：增加了跨人测试

使用公开 [CIP 数据集](https://zenodo.org/records/6480543) 的 5 名受试者：3 人训练、1 人选模型、1 人留作测试。输入是 6 个惯性传感器的方向与加速度，以及从参考数据提取的头部高度；输出是以骨盆为中心的 22 个身体节段位置。选出的神经网络在未参与训练和选模型的第 4 号受试者上，四类动作等权平均误差为 **0.109054 数据位置单位**，固定平均姿态基线为 **0.146297**，相对降低约 25.5%。

| 动作 | 模型误差 | 固定平均姿态误差 |
|---|---:|---:|
| sequence | 0.108556 | 0.138818 |
| circuit | 0.111657 | 0.176539 |
| task | 0.082888 | 0.095890 |
| random | 0.133115 | 0.173940 |

Xsens 文档描述该系统的身体位置单位为米；但尚未直接证实本数据集 Excel 导出配置，故这里保留源数据单位。若其确为米，上述模型均值相当于约 10.91 厘米。数值与此前 FusionPoser 实验不宜直接比较：两次的身体点、参考数据和数据划分均不同。

这次处理先按六个传感器的数据包编号匹配，再借助同次参考姿态估计与参考序列的时差。测试对象只包含 1 名新受试者；头高和对齐使用了参考数据，因此它说明的是这个实验设置下的跨人效果。腕、脚等末端点误差相对较大，详见 [CIP 结果](../research/continuous_20261108/cip_results.json)。

## 2. 视觉识别：发现方向判断仍不稳定

先前 5 段新动作的正序、倒序共 10 图，模型与髋部几何方向一致 5/10；增加明显的髋部标记和参考线后，同一组为 8/10。再在另一组 10 图上得到 9/10，但该组参考答案全部属于“无明显变化”，不能代表另外两类。

随后从 4 位新来源的公开 CMU 动作片段中，按事先确定的规则选出上升、下降、无明显变化各 3 图。沿用参考线方案，**共 4/9 与几何参考一致**：上升 0/3、下降 2/3、无明显变化 2/3。这 9 图包含同一来源的重叠或逆序片段，不能视为 9 名独立人物。结论是该读图方案尚不能稳定判断髋部变化，不能靠上一次 9/10 就认为已经可靠。

针对这一种带固定颜色标记和参考线的图片，另外增加了直接读取标记位置的小工具，接近边界时返回“不确定”。开发后再用 16 个未参与该工具开发的公开动作源检查 160 个窗口：**154 个与几何参考一致，6 个接近边界而返回不确定**，没有观察到反向判断。其中上升 19/20、下降 19/20，其余对应“不确定”。同一动作的多个窗口和正倒序有关联，不能当作 160 个独立人物。该工具只适用于这种固定标记图片，结果不能代表视觉大模型准确率。

[balanced_manifest.json](../research/continuous_20261108/balanced_manifest.json) 保存选样规则、所有候选及参考值；[balanced_live.jsonl](../research/continuous_20261108/balanced_live.jsonl) 保存各图结果；`marker_holdout_results.json` 和 `marker_moving_holdout_results.json` 保存固定标记工具的测试结果。图片来源与脚本固定于 Git 版本，运行相应 `*_fetch.py` 可下载并核验文件。参考线本身来自已知几何，因此这个实验只考察带辅助线的图片比较。

## 3. Agent：改进依据检查并扩大离线验证

针对模型在模拟“自报无不适”场景套用“状态未知”固定句的问题，只修正这一种已知的矛盾措辞，动作选择和引用不变；最终候选文字仍由已引用的模拟次数生成。新增了免打扰状态类型不合法、缺少次数、重复 JSON 字段等测试。不适上报仍优先进入安全分支。

真实模型的小样本实验覆盖提醒候选、免打扰延后、信息不足时静默和不适分支。相关离线测试 148 项通过，另有标记读取器 5 项测试通过。项目 Python 3.12 回归为 **703 项通过、7 项跳过**；其中 CIP 预处理的 3 项测试已在 Python 3.11 另行通过。这些测试覆盖确定的工程条件。
