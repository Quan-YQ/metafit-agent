# 模拟动作观察与引用：运行说明

这是独立的非商业研究演示，使用 CMU 公开动作片段和虚构训练事件，验证“图片观察 → 几何对照 → 模拟绑定 → 候选引用 → R3 检查”的数据流。它不会向 App 或训练者展示反馈。

## 运行

在项目目录下运行以下命令，将向 DeepSeek 发送一张公开骨架图，最多调用一次，可能产生费用：

    py -3.12 examples/bound_motion_agent.py --live --prompt-key

在提示处输入自己的 DeepSeek 密钥，输入时不会显示；不要将密钥放进聊天或项目文件。程序遇到错误即停止，不自动重试。超时或失败可能已经计费，实际费用以服务商账单为准。

如果只想检查程序、不联网、不产生 API 费用，运行：

    py -3.12 examples/bound_motion_agent.py

离线模式使用人为指定的观察结果，不代表真实模型理解了图片。真实模式使用 DeepSeek 做图像观察，后续候选仍由离线替身生成，候选只能是 `silent`。

## 如何看结果

当以下字段同时出现时，表示本次模拟链路按预期完成：

- `binding_status: matched_simulation`：本地模拟事件事实、样本、图片、问题和观察之间的记录一致。
- `observation.comparison: matches_reference`：模型对髋部首尾变化的分类与骨架计算结果一致。
- `r3_status: reviewed`、`reference_check: passed_for_cited_ids`：研究适配器构造的候选引用通过现有 R3 范围检查。
- `effective_action: silent`、`may_display: false`：本次没有向训练者发送或展示反馈。

如果结果不同或模型表示不确定，流程会停止；这并不自动代表程序错误。保存完整输出便于排查，**不要保存或分享密钥**。

## 范围与限制

- 模拟绑定只是将虚构事件和公开片段组合起来，使用摘要检查内容是否一致。摘要不认证身份，也不能证明同一真实训练事件采集了该片段。
- `cited_fact` 的含义是“模型报告了什么”，不是动作真实情况。研究适配器为了复用 R3 范围检查，临时构造并加入一个模拟事实；它没有进入正式 R2 上下文、R5 持久化、App 契约或真实训练记录。
- 几何对照只检查首尾髋部高度方向，5% 为实验约定；R3 检查引用范围，不验证自然语言真实性，也不验证动作是否标准或安全。
- 当前 R3 免打扰状态使用模拟默认值；R5 会话安全确认、真实用户身份、跨设备状态、训练建议和 App 投递均不在本演示范围。
