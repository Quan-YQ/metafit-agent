# MetaFit Agent 非商业研究原型：评审交付说明

更新时间：2026-11-10。此版本可以作为**本机研究演示**交给评审者；它尚不是可向真实训练者提供指导或实际投递消息的产品。

## 快速运行

在本项目文件夹中打开 Windows PowerShell 并运行：

```powershell
py -3.12 examples\research_doctor.py
```

首次从评审包运行时，需先下载公开样本；本机已有样本时可直接运行。自检默认不联网：校验公开数据文件摘要，运行公开 IMU 的跨录制基线，并用离线模型替身检查两个模拟候选。`research_demo_ready` 只表示演示可运行，不是实际训练安全验收。结果中的“不同候选动作”由离线替身人为设定，不代表真实模型的选择。

如果公开数据缺失，可以运行 `py -3.12 examples\fusionposer_fetch.py --download`，从固定版本的 FusionPoser 公开仓库下载缺失文件并校验摘要。下载不自动重试、不覆盖已有文件。

## 研究目标与现状

| 方向 | 已有成果 | 当前边界 |
|---|---|---|
| 接入模型 API | DeepSeek、智谱 GLM 文本客户端；千问视觉模型用于公开骨架图研究 | 研究脚本，不是产品接口的真实健康数据流程 |
| 公开数据和骨架 | FusionPoser 六 IMU 与头高可生成预测骨架；CMU/AMASS 可本地绘制 | 预测骨架不是真实动作真值；实验室专有动捕数据尚未接入 |
| 图像交给 VLM | 5 段录制、90 张扩展图，两款千问同图同题 | 方向召回仍低，类别不平衡；只检验图像几何 |
| Agent 不固定回复 | 模拟决策支持 silent、notify、defer，引用范围受检验 | 研究候选不可显示或投递，尚未与真实 App 会话串联 |
| 对照实验 | 六家视觉模型横评；一次完整视觉→文本→R3 链路 | 不能由此断言动作或提醒正确，也不能替代真实设备验收 |

本机 HTTP 服务默认使用离线模型；真实模型调用只发生在独立研究脚本中。候选始终 `may_display=false`。

## 最新结果

2026-11-10 完成扩展链路：公开 IMU 与头高生成预测骨架，**5 段录制 × 6 个自然窗口 × forward/reverse/static 三种版本，共 90 张图**；两款千问全量评分。

- `qwen3.8-max`：**75/90（83.3%）**，三类平均 **73.5%**；上升 9/14、下降 9/14、无明显变化 57/62。
- `qwen3.8-flash`：**62/90（68.9%）**，三类平均 **48.1%**；上升 3/14、下降 5/14、无明显变化 54/62。
- 30 窗口聚类 bootstrap 的三类平均 95% CI：Max 56.6%–89.2%，Flash 36.5%–59.8%。
- 完整链路：Max 将 `imu_x2_4_forward` 读为 down（与参考一致）→ Flash 选择 `silent` → R3 `reviewed`；候选引用了视觉观察事实，但最终不展示、不投递。
- 182 次调用，usage 估算 ¥1.0097918 / ¥10；另有首轮 6 次 pilot 估算 ¥0.0331506。详见[完整报告](公开IMU链路扩展实测_20261110.md)和[演示页](../research/live_chain_20261110_expanded/results/run_A/index.html)。

六家视觉模型同图横评中，Kimi `kimi-k3.1-pro` 在 90 张 CMU 骨架图上的三类平均正确率为 96.7%；报告见[六家横评](../research/six_model_vision_20261110/横评报告.md)。

### 方法限制

- 5 段测试录制此前已用于本项目公开数据的开发或留出评估，**不是全新盲测**；同源窗口的三种版本也不是独立人物。
- 无明显变化占 62/90，总准确率会被抬高；主要指标是三类平均。上升/下降召回仍低，错误集中在阈值边缘和预测质量较差的窗口。
- 这 5 段的预测平均误差为 9.9–16.2，固定均值姿态基线为 13.5–24.7；其中两段比基线更差。预测骨架质量直接影响读图难度。
- 绿点方向校验 28/28 与几何参考一致，90 张重渲染摘要一致；因此错误来自读图判断，不是图像与标签反向。
- 首轮 pilot 只有 3 张边缘样本，按原门槛两款都不通过；扩展协议把 pilot 改为诊断、全部 90 张评分，图片、提示词和模型未改。该调整在报告中如实披露。
- 旧 18 张链路结果（Max 14/15、三类平均 66.7%）与新 90 张在样本、阶段和模型范围上都不同，不能直接比较。
