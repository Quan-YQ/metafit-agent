# MetaFit Agent 非商业研究原型：评审交付说明

更新时间：2026-11-07。此版本可以作为**本机研究演示**交给评审者；它尚不是可向真实训练者提供指导或实际投递消息的产品。

## 快速运行

在本项目文件夹中打开 Windows PowerShell 并运行：

```powershell
py -3.12 examples\research_doctor.py
```

首次从评审包运行时，需先按下文下载公开样本；本机已有样本时可直接运行。自检默认不联网：校验公开数据文件摘要，运行公开 IMU 的跨录制基线，并用离线模型替身检查两个模拟候选。`research_demo_ready` 只表示演示可运行，不是实际训练安全验收。结果中的“不同候选动作”由离线替身人为设定，不代表真实模型的选择。

如果公开数据缺失，可以运行 `py -3.12 examples\fusionposer_fetch.py --download`，从固定版本的 FusionPoser 公开仓库下载缺失文件并校验摘要。下载不自动重试、不覆盖已有文件。查看实验结果可运行 `py -3.12 examples\fusionposer_cross_record.py`。

真实模型的对照工具是 `examples/compare_vision_choice.py`：默认使用离线替身；显式启用 `--live` 才联网，每次最多一张公开骨架图和两次模拟文本请求。真实调用有费用，需自行安全配置环境变量；密钥不能写进项目。候选一律不可投递。

## 研究目标与现状

| 方向 | 已有成果 | 当前边界 |
|---|---|---|
| 接入模型 API | DeepSeek、智谱文本客户端；DeepSeek 图片观察已真实调用 | 公开样本研究，不是产品接口的真实健康数据流程 |
| 公开数据和骨架 | FusionPoser 的真实惯性数据可生成预测骨架；AMASS ACCAD + SMPL+H 可在本机绘制骨架 | AMASS 不是实测 IMU；FusionPoser 使用额外头部高度，关节布局和单位依据论文与数据结构推断 |
| 图像交给 VLM | 公开骨架图经模型观察，与首尾髋部几何方向对照 | 此几何对照不是专业动作质量标签；AMASS 衍生图未上传外部服务 |
| Agent 不固定回复 | 模拟决策支持 silent、notify、defer，引用范围受检验 | 研究候选不可显示或投递，尚未与真实 App 会话串联 |
| 对照实验 | 相同虚构事件可比较是否有模型视觉观察 | 两组真实对照的动作均为 silent；一次补充实验中图像组引用了视觉观察、纯文本组没有，不能由此断言动作或提醒正确 |

## 已有的实验证据

- 在三段公开 FusionPoser 录制上，以一段训练、两段独立录制测试：平均关节误差分别为 **69.337 cm / 58.809 cm**；训练集均值姿态基线分别为 **33.826 cm / 29.740 cm**。这两次预测比基线差，故该单录制预测器尚不能作为通用模型。
- 使用三折“每次留出一段录制”，三个测试误差为 **10.872 / 30.347 / 8.060 cm**，对应均值姿态基线 **29.028 / 25.126 / 21.028 cm**。其中一折仍差于基线。录制者身份未知，不能称为跨人验证；数值依赖当前对输入与标签布局的推断。
- 两个公开 CMU 动作图分别完成一次真实模型“有视觉观察 / 纯文本”对照；观察的髋部变化方向均与几何参考一致，两组候选动作均为 silent。另一次补充对照也为 silent，但视觉组引用了模型观察，纯文本组没有。模型存在随机性，样本过少，不能推断稳定性或准确率。
- AMASS 本地实验检查了 6 个选定片段可以计算 6 帧骨架；初步人体头脚方向与 Z-up 显示一致，但不替代官方实现的关节、坐标和渲染比对。该路径不发送数据到 DeepSeek。
- 2026-11-07 在未下载可选研究数据的隔离副本中运行 Python 3.12 完整回归：682 项通过、5 项跳过；其中 4 项需要 NumPy，已在 Python 3.11/NumPy 环境单独通过，另 1 项需要 FusionPoser 样本。不同环境的跳过项可能不同。

## 数据来源及许可

- [FusionPoser 作者仓库](https://github.com/LuzyCat/FusionPoser)说明公开真实数据使用 6 个 Xsens DOT 与 OptiTrack；仓库 MIT 许可及固定版本、哈希见 `data/fusionposer/来源说明.md`。本实验还用到头部高度输入。
- [AMASS 许可](https://amass.is.tue.mpg.de/license.html)和 [MANO/SMPL+H 许可](https://mano.is.tue.mpg.de/license.html)为个人单用户、非商业用途，并限制向第三方提供。不要把受限压缩包、模型或衍生图直接打包上传；是否可以通过第三方工具处理或发送，先核对许可与服务设置。AMASS 和模型压缩包应由使用者自行合法获取。
- AMASS 本地代码 `examples/amass_local_skeleton.py` 使用本机 Python 3.11 和 NumPy；该路径不影响主项目 Python 3.12 的零运行时依赖。

## 交付前仍需完成的工作

1. 向数据作者核对 FusionPoser 输入窗口、坐标单位及参考标签布局；基于更多不同动作、不同人建立可复现的独立测试，改善目前不稳定的预测结果。
2. 与官方实现核对 AMASS 人体模型、坐标系和显示结果，确认数据及派生图送外部服务的许可后才设计真实视觉评测。
3. 真实传感器协议、标定、设备/事件来源绑定、丢帧和同步处理尚未完成；现在不能实时接个人设备。
4. 在有真实 App、身份鉴权、跨设备状态与投递方案后完成联调，并由专业人员审查提示和训练安全；R3 引用检查不保证内容正确或安全。

以上事项需要新的数据、真实设备、对接方或专业验收，当前研究演示不能替代这些条件。
