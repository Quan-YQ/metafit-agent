# 骨架图读图实验

这个小实验用一张人工绘制的示意图，检查 DeepSeek 能否接收图片并描述画面。左侧人物大致直立，右侧人物髋部和膝部有明显弯曲。它不是从真实人体或动作数据生成的，也不能用来判断真实动作是否安全。

## 第一步：检查程序

在项目目录的 PowerShell 中运行：

```powershell
py -3.12 examples/check_vision.py
```

看到“骨架图片已就绪”和“未联网”，表示本地准备正常。这一步不会调用模型，也不会产生 API 费用。

## 第二步：真实读图

准备好自己在 DeepSeek 开放平台创建的 API 密钥，在同一个目录运行：

```powershell
py -3.12 examples/check_vision.py --live --ask-key
```

按提示输入密钥；输入时屏幕不会显示字符，输入完按回车。不要把密钥发到聊天中。也可以预先设置 `DEEPSEEK_API_KEY` 环境变量，然后省略 `--ask-key`。

程序只发送一次请求：图片和文字提示会发送给 DeepSeek，可能产生 API 费用，具体费用以服务商账单为准。程序不自动重试，发生超时或网络错误时，服务商是否计费仍可能不确定。

## 第三步：看结果

检查回答能否分清左、右人物，是否描述出左侧较直立、右侧髋膝弯曲。若信息看不清，合理的回答可以说明无法判断。模型回答只是一次观察结果，不代表它能可靠分析真实动作，也不应作为训练建议。

可以把**不含密钥**的模型回答、耗时、token 用量或错误提示提供给协作者，一起判断下一步。`HTTP 401` 通常需要检查密钥；其他错误可以先记录提示，不要反复重试。

需要把内置示意图保存为文件查看时，可以运行 `py -3.12 examples/make_vision_sample.py`。如需使用另一张模拟 PNG，可在命令末尾加 `--image 图片路径`；请不要上传真人照片或真实健康数据。
