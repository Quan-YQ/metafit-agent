# 六家骨架读图横评归档

阅读 [横评报告](横评报告.md)，或在本机浏览器打开 [图表页面](index.html)。`paired_results.json` 为六家共同完成样本的结果，逐图响应按提供商保存在 `responses/*.jsonl`。`manifest.json` 和 `images/` 保留所有计划样本及参考，`budget.json` 保留本次费用预留与结算。

## 无网络复核

在本目录运行 `python replay.py`。脚本核查冻结配置、每张图片及提示词、每条实际请求摘要、原始响应摘要、六家共同样本和计分、费用账本；不需要密钥、不访问网络。`frozen_sources` 留存实际执行的源码原字节，`analysis_sources` 留存评分、图像核查与报告生成源码供审查；这些原始源码不是面向生产环境的调用入口。数据出处与样本关联在 [预登记](PREREGISTRATION.md) 和 `manifest.json` 中。

120张CMU图片来自60个动作窗口的有线/无线两个版本；18张IMU预测图片来自较早的研究运行。答对骨架图髋部升降不等于动作评估或训练指导已经验证。全部历史成绩及本轮失败响应按原貌保存。
